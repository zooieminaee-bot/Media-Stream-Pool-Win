# MediaStreamPool Win v0.1.0

Initial versioned Windows x64 release.

- .NET 10 / WinUI 3 desktop application
- Self-contained Windows x64 publish
- SQLite local persistence
- Streams, APIs, decoded payloads, scanner, settings and about UI

The release artifact is the complete Windows x64 publish directory packaged as a ZIP. The main EXE is not intended to run by itself without the accompanying files.
